⚠️ ORS API Key Required
Make sure your OpenRouteService API key is set in .env before running the integration test. Sign up at openrouteservice.org/dev/#/signup for a free tier key.

📡API Endpoints

POST   /api/internal/aggregate           Trigger DBSCAN clustering
GET    /api/lots                          List lots with filters
POST   /api/orders                        Create new order
GET    /api/orders/{order_id}             Get order details
POST   /api/routing/optimize              Optimize delivery route
POST   /api/routing/compare               Compare routing strategies
POST   /api/settlement/payout             Process farmer payout
